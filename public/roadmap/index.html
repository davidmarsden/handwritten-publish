After v1.0

Road
map

Helping Hand now does what it was built to do. Writing Hand, Publish Hand and BUM Hand are all live, and the core suite is officially v1.0.

What remains below is a shelf of possibilities, not a release calendar. New work should happen when real use exposes a real itch.

Release boundary

v1.0 complete

The suite now covers the three workflows that justified building it in the first place: write by hand and send to Micro.blog, build richer mixed-media handwritten posts, and batch-upload ordinary files without creating posts.

The rule from here: maintain what works, fix genuine friction, and resist turning a small publishing toolkit into another CMS.

Live in v1.0

Three hands, three jobs

  • Writing Hand: reMarkable email/transcription → Micro.blog
  • Publish Hand: handwriting, photos and PDFs → web-ready posts
  • BUM Hand: mixed JPEG/PNG/WebP, MP3/M4A and PDF batch uploads
  • Photo Collections directly from BUM Hand
  • Local image optimisation and Android/Google Photos batch staging
  • Canonical URL, Markdown and HTML output
  • Self-hosted setup and shared open-source infrastructure

Only if useful

Possible future work.

None of these is promised. They stay visible so good ideas are not lost, but they only move when there is a concrete reason to build them.

Maintenance

Keep the hands working.

Reliability

Protect the workflows that already work.

Bug fixes, API changes, browser regressions and Micro.blog compatibility take priority over speculative new features.

Documentation

Keep it easy to take home.

Keep setup, architecture and release notes current so somebody else can understand and self-host the suite without reverse-engineering it.

Product boundary

Small on purpose.

A new feature belongs only when it removes repetitive publishing machinery while leaving the original work and Micro.blog in charge.

Open source

Portable, inspectable, yours.

Prefer ordinary files, standards and explicit APIs over lock-in. Helping Hand should remain useful even when parts of the stack change.
