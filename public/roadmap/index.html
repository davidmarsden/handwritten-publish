Road
map

Helping Hand now does what it was built to do. Writing Hand, Publish Hand, BUM Hand and Markdown Hand are live, and the core suite is officially v1.0.

What remains is a shelf of possibilities, not a release calendar. New work happens when real use exposes a real itch.

Release boundary

v1.0 complete

The four workflows are now covered: write by hand and send to Micro.blog; build richer mixed-media handwritten posts; batch-upload ordinary files without creating posts; and publish carefully prepared Markdown without a web editor rewriting it.

Four hands, four jobs: Writing Hand, Publish Hand, BUM Hand and Markdown Hand.

The rule from here: maintain what works, fix genuine friction, and resist turning a small publishing toolkit into another CMS.

Reliability

Protect what already works.

Bug fixes, API changes, browser regressions and Micro.blog compatibility take priority over speculative features.

Documentation

Keep it easy to take home.

Keep setup, architecture and release notes current so the suite remains understandable and self-hostable.

Product boundary

Small on purpose.

A new feature belongs only when it removes repetitive publishing machinery while leaving the original work and Micro.blog in charge.

Open source

Portable, inspectable, yours.

Prefer ordinary files, standards and explicit APIs over lock-in.
