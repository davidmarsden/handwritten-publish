What comes next

Road
map

Helping Hand started with one small publishing itch. The aim is to keep it that way: useful, understandable tools that remove repetitive machinery without getting between you and the thing you made.

This is a direction of travel, not a release calendar. Priorities can move as the tools get used in real life.

Main priority

BUM Hand

Batch Uploader for Micro.blog is the smallest tool in the suite and probably the one with the biggest obvious runway. Its job should stay gloriously simple: give it files, put them on Micro.blog, give you useful things back.

The rule: make batch work less tedious without turning BUM Hand into a media library of its own.

Fast in, useful outNo post requiredYour Micro.blog accountNo token storage

Live now

The useful first cut

BUM Hand currently handles the common image-upload job cleanly.

  • PNG, JPEG and WebP
  • Up to 5 MB per file
  • Up to 30 files in a batch
  • Queued uploads with retry
  • Copy URLs, Markdown or HTML

Next

Better batches

Polish the workflow that already exists before adding breadth.

  • Clearer per-file progress and failure states
  • Better handling of large or mixed batches
  • More useful result selection and copying
  • Small quality-of-life improvements discovered through real use

After that

More media

Broaden beyond the first image-only allow-list where Micro.blog supports it safely.

  • Additional Micro.blog-supported media types
  • Audio and other useful file uploads where the API permits them
  • Keep validation explicit rather than accepting arbitrary files
  • Reuse the same upload core in Publish Hand where it makes sense

Explore

Useful destinations

Make uploaded media easier to do something with, without inventing another CMS.

  • Output formats tailored to common publishing jobs
  • Faster paths from a batch into a post or photo workflow
  • Explore Micro.blog collection/favourite-photo workflows where the platform API makes that practical
  • Portable results rather than lock-in

The rest of the suite

Keep the other hands sharp.

Writing Hand

More native, not more complicated.

Keep improving the paper → email → web path, metadata handling and setup experience while preserving the one-action feel from reMarkable.

Publish Hand

A better workbench.

Keep refining mixed handwriting/photo/PDF documents, publishing metadata and the portable .handpub format. Shared media work should move into common plumbing rather than duplicate code.

Helping Hand

A small suite, on purpose.

The launcher, setup and documentation should make the family understandable to somebody who did not build it. New tools only belong here if they solve a similarly concrete publishing problem.

Open source

Easy to take home.

Keep the repository readable, the setup guide current and self-hosting straightforward so other people can run their own Helping Hand rather than depending on a central account service.
